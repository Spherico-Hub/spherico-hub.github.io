## Installing Java

<Aside>If you already have Java installed, you can skip this section.</Aside>

<Steps>
  1. On Prism Launcher's top bar, select `Settings`.
  2. On the launcher settings, navigate to  `Java > Installations`.
  3. On the Installations tab, select `Download`.
  4. Select the appropriate version of Java. The current recommendation is the the latest version of Adoptium Java 21.
  5. Select `Download`.
</Steps>

## Installing the modpack

<Steps>
  1. Download the file through the button below.
  2. In Prism Launcher, **create** a new instance, go to **import** and **select** the file you have downloaded.
  3. Launch the instance **at least once** and let it load to the main menu.
</Steps>

<LinkButton
  href="https://github.com/Spherico-Hub/modpack/releases/latest/download/SphericoMC.5.zip"
  icon="external"
  iconPlacement="start"
>
  Download the modpack
</LinkButton>

<Aside type="caution" title="Analog Audio">
  If Minecraft asks you to download AudioLib for Analog Audio, you **must** click on `download and install`.
  Not doing so will prevent Analog Audio from functioning.
</Aside>

<Aside type="tip" title="Create: Deep Seas">
  If Minecraft asks you to set up defaults for Create: Deep Seas, you can safely use the provided defaults.
</Aside>

<Aside type="note" icon="seti:config" title="Keeping your configuration">
  If you want to migrate your configuration, [follow this guide](/minecraft/troubleshooting#configuration-migration).
</Aside>

## Updating the modpack

The modpack will generally update itself upon launching the game.

<Aside type="danger" title="Neoforge Updates">
  Some updates require manual intervention for upgrading NeoForge.
  Please refer to [the troubleshooting page](/minecraft/troubleshooting#updating-neoforge) for more information.
</Aside>

## Connect to the server

The server should be conveniently be in your multiplayer menu already!
Otherwise just enter `services.spherico.one` in a new server window.

<Aside type="danger" icon="error" title="Whitelist">
  Make sure you have given your Minecraft username to an administrator, otherwise the whitelist will
  prevent you from joining the server.
</Aside>
