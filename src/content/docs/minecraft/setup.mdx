## Installing Prism Launcher

<Tabs>

<TabItem label="Windows" icon="seti:windows">
  Get it from the [official source](https://prismlauncher.org/download/windows/). If you fancy your
  terminal instead, enter: `winget install prismlauncher` or `winget install
  prismlauncher.prismlauncher`.
</TabItem>

<TabItem label="macOS" icon="apple">
  Get it from the [offical source](https://prismlauncher.org/download/mac/).
</TabItem>

<TabItem label="Linux" icon="linux">
  Flatpak is a prerequisite.\ Enter: `flatpak install flathub org.prismlauncher.PrismLauncher`
</TabItem>

</Tabs>

## Installing Java

<Aside>If you already have Java installed, you can skip this section.</Aside>

<Steps>
  1. On Prism Launcher's top bar, select `Settings`.
  2. On the launcher settings, navigate to  `Java > Installations`.
  3. On the Installations tab, select `Download`.
  4. Select the appropriate version of Java. The current recommendation is the the latest version of Adoptium Java 21.
  5. Select `Download`.
</Steps>

## Installing the modpack

<Steps>
  1. Download the file through [this link](https://github.com/Spherico-Hub/modpack/releases/latest/download/SphericoMC.5.zip).
  2. In Prism Launcher, **create** a new instance, go to **import** and **select** the file you have downloaded.
  3. Launch the instance **at least once** and let it load to the main menu.
</Steps>

<Aside type="note" icon="seti:config" title="Keeping your configuration">
  If you want to migrate your configuration, [follow this guide](/minecraft/troubleshooting).
</Aside>

## Updating the modpack

The modpack will generally update itself upon launching the game.

<Aside type="note" icon="seti:info" title="Major season-to-season updates">
  When upgrading between seasons, it is best to re-install the modpack from scratch.
</Aside>

# Connect to the server

The server should be conveniently be in your multiplayer menu already!
Otherwise just enter `services.spherico.one` in the new server window.

<Aside type="danger" icon="error" title="Whitelist">
  Make sure you have given your Minecraft username to an administrator, otherwise the whitelist will
  prevent you from joining the server.
</Aside>
